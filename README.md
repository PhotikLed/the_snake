# Проект «Изгиб Питона» (The Snake)

Финальный проект по курсу «ООП и другие полезные вещи, которые нужно знать» в рамках программы «Прикладной искусственный интеллект» (Яндекс Практикум / УрФУ).

## Описание игры

Классическая аркадная игра «Змейка», написанная на Python с использованием графической библиотеки Pygame и объектно-ориентированного программирования.

### Основные механики:
- **Игровое поле:** экран размером 640x480 пикселей, разделенный на сетку 20x20 точек (32x24 ячейки).
- **Сквозные границы:** змейка не разбивается о стены, а циклически телепортируется на противоположную сторону поля.
- **Еда:** яблоко случайным образом появляется на свободном участке поля (гарантированно вне тела змейки).
- **Рост и очки:** при поедании яблока длина змейки увеличивается на один сегмент, а яблоко перемещается на новую позицию.
- **Самоукус:** при столкновении головы змейки с собственным телом происходит сброс в стартовое состояние.
- **Отрисовка:** затирание только хвостового следа на каждом шаге вместо перерисовки всего окна.

## Управление

- **Стрелки на клавиатуре** или клавиши **W, A, S, D** — изменение направления движения (запрещен разворот на 180 градусов).
- **Escape** — выход из игры.

## Установка и запуск

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Запуск игры

```bash
python3 the_snake.py
```

### 3. Запуск тестов

```bash
pytest -v
```

### 4. Проверка соответствия стандартам PEP 8

```bash
flake8 .
```
